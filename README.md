# Sale Order Approve from List View

## Overview
This module allows users to confirm or cancel sale orders directly from the list view without opening each order individually.

## Features
- Confirm sale orders from list view
- Cancel sale orders from list view
  
## Installation
1. Copy module to your Odoo addons directory
2. Update Apps List
3. Install the module
